# Street Stars

**Give the streets a memory.**

Street Stars is an open-source experiment exploring a finite layer of digital Stars anchored to real streets.

## The primitive

**DISCOVER → WALK → FIND → CLAIM → LEAVE → RELEASE → DISCOVER**

A Star is a permanent place marker. A claim is temporary. A memory belongs to the person who leaves it there. Stars are not property and are not transferable.

When a claimant releases a Star, it enters a random resting period. It then becomes available again on a first-come, first-served basis to someone physically present at the location.

## MVP 01 — Berlin

Edition I · 2026–2030

The first browser primitive deliberately avoids marketplaces, payments, crypto, NFTs, followers, likes, comments, messaging, AI and advertising.

## Current prototype

This first primitive runs entirely in the browser using local storage. It demonstrates the core interaction and rules before introducing shared persistence, authentication, moderation, privacy controls and a real map/geolocation backend.
